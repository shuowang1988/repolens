Method boundaries (read first)
1) Weights are not supervised. This project has no labelled dataset; the weights come from unsupervised diagnostics and explicit design trade-offs, and should not be read as an optimum.
2) Language discrimination is an emergent behaviour, not a designed guarantee. Language is one of eight components; measured cross-language separation comes from the weighted combination and exceeds random expectation on this corpus, but that is not claimed to hold on arbitrary corpora.
3) Structure and content are complementary, not substitutes. Mean Top-5 overlap is only 0.371, so the two signals are close to orthogonal and should be used together.
4) Historical defect on record: the v1 size component could never reach zero (measured floor 0.304), so a 1640x size difference still earned about a third of the credit. The current piecewise-linear form can award zero.
